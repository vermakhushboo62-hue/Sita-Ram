# Sita-Raam

A daily manifestation practice in a single web page.

- **3-6-9 ritual**: write your focus intention 3 times in the morning, 6 in the afternoon and 9 at night. The page tracks your streak of complete days.
- **Intentions**: set, edit and rewrite intentions in the present tense, tagged by area of life.
- **Rewrite for me**: turns a rough wish ("I will be healthy someday") into affirmations ("I am healthy now.").
- **Signs**: log coincidences and small wins under each intention.
- **It arrived**: mark an intention as come true and see how long it took.
- **Three thanks**: three gratitude lines each day.
- **Visualise**: a 60-second breathing timer with your intention on screen.
- **Moon phase**: today's phase with a matching prompt.

## Running it

Open `index.html` in a browser. There is no build step and nothing to install.

Entries are saved in the browser's local storage, so they stay on that device and browser only.

To put it online with GitHub Pages: open **Settings → Pages**, set the source to the `main` branch and the root folder, and save.
